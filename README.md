## 📦 单文件 EXE

在 [Releases](https://github.com/AuR3L1US07/course-assistant/releases) 下载 **`CourseAssistant-v0.2.2-windows-x64.exe`**，可以直接放在桌面并双击运行。无需解压压缩包、安装 Python 或 Node.js；浏览器优先使用 Chrome；未安装 Chrome 时自动使用 Microsoft Edge，两者都未安装才提示安装。

浏览器运行时、脚本与字体映射已内嵌，启动时自动解压至系统临时目录，正常退出后清理。桌面不会生成 `.runtime`、脚本或 `data` 文件夹。

登录信息、题库、课程记录、设置及浏览器缓存会在 **`%LOCALAPPDATA%\CourseAssistant\data\`** 按需创建并持久保存。可以把这个路径粘贴到资源管理器地址栏打开。更换或移动 EXE 后仍使用同一份缓存；程序更新不会主动删除它。账号密码、API 密钥和保存的会话仍使用当前 Windows 用户加密，不随 EXE 分发。

旧版 v0.1.0 压缩包使用 EXE 旁的 `data/`。如需迁移自己的旧数据，先退出程序和独立浏览器，在同一 Windows 账号下将旧 `data/` 备份后放到上述新位置；不要覆盖已有的新数据。源码版仍使用项目内 `data/`，不会自动导入开发者的本机数据。Release 同时提供 SHA-256 校验文件。

下面的安装步骤面向从源码运行的用户。

## 🚀 安装启动

### 1. 准备环境

- Windows 桌面环境：账号加密依赖 Windows DPAPI。
- Python 3.12：安装后应能执行 `python --version`。
- Google Chrome 或 Microsoft Edge：优先 Chrome，没有 Chrome 时自动使用 Edge，程序使用独立资料目录。
- 源码部署需要 Node.js 20 或以上版本和 npm，以准备浏览器组件。

在仓库页面点击 **Code → Download ZIP** 后解压，或通过 Git 克隆。在源码目录打开 PowerShell，执行以下步骤。

> 仓库只包含源码。`.runtime/`、`data/`、EXE 和个人截图不会上传；首次下载后必须准备依赖，不能直接认为源码包是完整安装包。

### 2. 安装界面依赖

```powershell
python -m pip install --target .runtime/python-libs -r requirements-ui.txt
```

项目通过 `requirements-ui.txt` 固定 PySide6-Essentials 版本，界面自动加载 `.runtime/python-libs`。

### 3. 准备浏览器组件

从 Node.js 官方渠道安装 Node.js 20 或以上版本，确保 `node`、`npm` 可用。首次安装、目标 `.runtime/playwright-core` 尚不存在时运行：

```powershell
New-Item -ItemType Directory -Force .runtime | Out-Null
Copy-Item -LiteralPath (Get-Command node.exe).Source -Destination .runtime/node.exe
npm install --prefix .runtime --no-save playwright-core@1.62.1
Copy-Item -Recurse -LiteralPath .runtime/node_modules/playwright-core -Destination .runtime/playwright-core
```

项目直接加载 `.runtime/playwright-core`，只装在 `node_modules` 中还不够。程序使用系统 Chrome 或 Edge，不需要另行下载 Playwright 浏览器。

```text
课程助手/
├─ 启动.cmd
├─ qt_app.py
├─ browser_worker.cjs
├─ requirements-ui.txt
├─ .runtime/                  # 本机依赖，不上传
│  ├─ node.exe
│  ├─ playwright-core/
│  │  └─ package.json
│  └─ python-libs/
└─ data/                      # 使用时自动创建，不上传
```

### 4. 打开程序

双击 **启动.cmd**，或运行：

```powershell
python qt_app.py
```

`python app.py` 也打开同一界面。首次使用没有账号和课程记录，需要自行登录。

## 👤 平台登录

### 方式 A：网页登录，适合扫码与验证码

1. 点击顶部 **账号**，左侧选择目标平台。
2. 无需填写软件内的账号密码，点击 **打开网页登录**。
3. 在独立 Chrome 内完成账号登录、扫码或验证码。
4. 等待软件检测登录完成，最长约五分钟。需要复查时点击 **验证已完成，重新检查**。
5. 返回 **课程**，选择同一平台，点击 **检查课程信息**。

网页中输入的密码不会复制到软件账号表单；保存的会话按平台隔离，过期后需要重新登录。

### 方式 B：保存账号并登录

1. 进入 **账号** 并选择平台。
2. 填写平台账号密码，点击 **保存并登录**。
3. 程序加密保存并验证登录；出现验证码时，在打开的网页中手动完成。
4. 确认 **登录成功**，再检查课程。

MOOC 支持手机号密码及网易邮箱密码登录。修改账号密码后需要重新认证。**清除保存**只清除保存的账号，不退出浏览器会话。

> 独立浏览器使用 `data/browser`，与日常 Chrome 的资料目录分开。不要同时运行两个课程助手实例，以免争用目录。

## 📚 课程检查

1. 点击顶部 **课程**，选择平台。
2. 点击 **检查课程信息**，等待底部状态栏提示完成。
3. 左侧切换分类，搜索框输入课程名称缩小范围。
4. 选中课程查看详情，需要核对时点击 **打开选中课程**。
5. 在平台完成任务后再次检查，更新统计。

检查通常在后台运行。失败、取消或登录失效会保留旧数据；旧记录标为待复查，不视为本次已完成。未知数量保持待确认，不自动当作零。

| 平台 | 分类 | 统计口径与限制 |
| --- | --- | --- |
| 超星泛雅 / 学习通 | 章节、任务、作业、讨论、学习次数 | 章节按任务点；任务关注进行中活动；作业结合提交状态；讨论结合明确要求、发帖和回帖记录 |
| 中国大学 MOOC | 课件、讨论、测验、作业 | 读取 MOOC 与 SPOC；课件合并视频和文档并去重；完成状态取自平台标记；可用时单独显示自评与互评 |
| 长江雨课堂 | 视频学习、习题、考试 | 按学习内容目录及完成标记统计；考试只保留分类与入口 |

仅统计本次可见的已发布项目，不推断未来内容。无对应要求的课程可能不显示，例如章节任务点为 0/0 的课程。检查课程本身不播放课件、不提交答卷。

## ▶️ 播放与任务控制

### 选中课程或批量处理

1. 先完成一次成功的课程检查。
2. 选中课程，按需设置播放速度。
3. 点击 **刷所选课程**；批量处理使用 **自动刷课**。
4. 在任务选项中选择当前平台支持的处理类型并启动。
5. 观察底部状态栏或浏览器悬浮面板，按需暂停、继续、停止。
6. 结束后重新检查课程，确认平台实际记录。

超星尝试识别 HTML 视频与明确的下一节入口。可选 0.75、1、1.25、1.5、2、4、8、10、16 倍速；**自动最高**尝试可生效档位，失败后降低。网站可能限制倍速，界面显示实际生效速度；播放速度不保证平台按同比例累计学时。

长江雨课堂根据目录完成勾跳过已完成项目，支持视频与习题流程；习题安全核验由用户在网页完成。MOOC 自动播放当前未启用。遇到未知页面或无法确认结果时，需到网页核对。考试不自动开始、作答或交卷。

### 浏览器悬浮面板

已支持的流程会显示控制条，可 **暂停 / 继续 / 停止**。支持时还可选择 **刷视频、浏览 PPT / 文档、做题** 并点击 **执行指令**。手动任务完成后停留当前章节，选择 **恢复自动刷课**继续。具体指令以当前平台显示为准。

> 做题流程可能向平台提交答案。启动前检查任务选项与 API 配置，运行中关注网页提示并核对结果。

### 超星学习次数

进入 **学习次数**，点击 **补足所选次数**或 **自动补足学习次数**。程序先读取明确要求和当前计数，需要补足时每隔约 5 秒刷新章节，最多每 10 次刷新复查平台计数。达标后停止；连续三次核对未见增加、登录失效或读取失败时暂停。刷新次数不会直接写成本机已完成次数，也不保证所有学校按刷新计数。

## 🔑 API 配置

只查看课程和进度无需配置 API。已接入的习题处理需要可用的模型服务。

1. 点击顶部 **答题 API**。
2. 选择服务商与模型，核对接口地址。
3. 填写自己的 API 密钥，设置超时，点击 **保存配置**。
4. 点击 **测试连接**，确认成功后再启动习题任务。

| 配置项 | 如何填写 |
| --- | --- |
| 官方 API 地址 | 服务商提供的基础地址，保留 `/v1` 等前缀；程序追加 `/chat/completions`，也接受完整接口地址 |
| 模型名称 | 使用该账号有权限调用的模型标识；含图题需要支持图片输入的模型 |
| API 密钥 | 使用自己的模型服务密钥，不要填写课程平台密码 |
| 请求超时 | 默认 45 秒，界面允许在 5–3600 秒范围内调整 |

**测试连接和答题请求可能产生费用。**余额、模型权限和可用性由服务商决定；超时不保证服务端停止生成或计费。

题干、选项及必要的题目配图或渲染截图会发送到所配置的 API 地址。平台账号密码和课程 Cookie 不作为答题请求内容提供给模型。请核对服务商可信度，避免向模型发送个人敏感信息。

状态栏显示请求次数和服务商返回的 token 用量。`data/ai-usage.jsonl` 记录时间、模型、题数、状态与用量，不记录密钥、题目或答案；未返回用量时显示未知。模型可能答错，应自行核对。

## ⚙️ 设置与数据管理

| 设置或操作 | 效果 |
| --- | --- |
| 启动时自动检查课程 | 启动后自动检查，关闭后记住选择 |
| 减少动画 | 关闭页面和开关过渡，让操作即时响应 |
| 清除保存 | 清除对应平台保存的账号，不清除浏览器登录 |

## 🔐 隐私与安全上传

下表中的 `data/`，在单文件 EXE 中位于 `%LOCALAPPDATA%\CourseAssistant\data\`，从源码运行时位于项目目录。题库保存在其中的 `quiz_bank.json`，在收集到可用答案时自动写入，下次启动继续读取；题库与课程记录均是个人缓存，不随程序分享。

**源码不需要真实账号、密码、API 密钥或个人课程数据。首次使用由使用者自行配置。**

| 本机内容 | 存放位置与处理 |
| --- | --- |
| 平台账号密码 | `data/accounts.json`，当前 Windows 用户 DPAPI 加密 |
| API 配置 | `data/settings.json`，密钥加密，地址和模型等配置不是全部加密 |
| 保存的网页会话 | `data/web-session-*.bin`，按平台加密 |
| Cookie、网站存储与缓存 | `data/browser*`，含登录资料，整个目录应保密 |
| 课程记录、偏好和用量记录 | `data/`，可能含个人学习信息，不上传 |
| 调试与预览截图 | `.test-artifacts/`，可能含个人课程，不上传 |

`.gitignore` 排除个人数据、本机运行时、构建产物、助手记忆、环境密钥文件、证书、数据库与日志。加密文件同样属于个人数据，不能因为加密就随源码分享。DPAPI 密文不能作为跨电脑通用配置。

提交前查看 `git status` 与 `git diff --cached`，只提交确认安全的源码和文档。忽略规则不会移除已跟踪文件；若将来误提交密钥，应立即在服务商撤销或轮换，并清理相关历史。私有仓库也需要这些措施。

## ❓ 常见问题

<details>
<summary><b>双击后没有窗口，或找不到 Python / PySide6？</b></summary>

在源码目录运行 `python qt_app.py` 查看错误。确认 Python 3.12 可用，并按安装步骤准备界面依赖。`启动.cmd` 遇到错误会暂停窗口，便于查看提示。

</details>

<details>
<summary><b>提示缺少浏览器组件或未找到浏览器？</b></summary>

确认 `.runtime/node.exe`、`.runtime/playwright-core/package.json` 存在，并已安装 Chrome 或 Edge。仅安装 Python 依赖不能补齐浏览器组件。

</details>

<details>
<summary><b>日常 Chrome 已登录，软件仍说未登录？</b></summary>

软件使用独立浏览器。到账号页点击“打开网页登录”，在该窗口登录后重试；会话过期或平台要求验证码时需重新验证。

</details>

<details>
<summary><b>课程不显示，或出现未识别、待确认、待复查？</b></summary>

检查平台、分类和搜索条件，再重新检查课程。无该分类要求的课程可能被过滤；待确认可能表示目录未完整读取、页面不兼容、状态未知或访问失败。打开课程核对，必要时重新登录。

</details>

<details>
<summary><b>无法连接课程浏览器？</b></summary>

停止当前任务，关闭课程助手打开的独立 Chrome 后重试；日常 Chrome 不必关闭。不要同时运行多个实例或在任务中移动浏览器资料目录。

</details>

<details>
<summary><b>API 失败、图片题不支持或超时？</b></summary>

检查地址前缀、模型标识、密钥、余额、权限与网络；图片题要求图片输入能力。复杂题目可适当延长超时。反馈问题前先删除密钥和个人信息，不要直接上传完整原始日志。

</details>

<details>
<summary><b>播放结束或停止后，进度没有更新？</b></summary>

停止会等待已启动操作退出，平台也可能延迟更新。重新检查或打开课程核对；播放器结束、刷新次数或本机缓存不能替代平台完成记录。

</details>

<details>
<summary><b>怎样分享给别人？</b></summary>

分享源码及必要依赖，接收方自行登录。不要附带 `data/`、个人截图、日志、助手记忆或含这些内容的压缩包。仓库不含运行时，接收方需按安装说明准备环境。

</details>

安装依赖后运行 Python 测试：

```powershell
$env:PYTHONPATH = (Join-Path $PWD '.runtime/python-libs')
$env:QT_QPA_PLATFORM = 'offscreen'
python -m unittest discover -s tests -v
```

按文件运行 Node.js 测试，例如：

```powershell
.\.runtime\node.exe tests/test_mooc_scanner.cjs
```

模拟测试通过不等于所有学校、账号与平台页面都已实机验证。

界面参考公开的 [PCL 控件设计](https://github.com/Meloong-Git/PCL)，Qt 控件为独立实现，不包含其游戏或账号模块。设计参数见 [UI_REFERENCE.md](UI_REFERENCE.md)。
